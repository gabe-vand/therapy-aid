Platform & hosting

  • ✓ Bun workspace: backend (Hono), frontend (Vite + React 18), packages/shared types.
  • ✓ SQLite database (bun:sqlite + Drizzle), idempotent DDL applied at boot from backend/db-schemas/.
  • ✓ Docker Compose stack on the Raspberry Pi: api, web (nginx, SPA + /api proxy), ts (Tailscale sidecar).
  • ✓ Served over HTTPS at therapy-aid.elephant-trench.ts.net, reachable only from the tailnet (Funnel off, no public ports).
  • ✓ /ship skill: commit → PR → redeploy to the Pi, verified by the live revision on /api/health.
  • ✓ Architecture tests: layering import bans and the 200-line file cap.
  • CI (GitHub Actions running bun run test on PRs).
  • Automated SQLite backups off the Pi.
  • Authentication — today anyone on the tailnet can use the app.
